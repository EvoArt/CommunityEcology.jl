CommunityEcology.jl

CommunityEcology.jl analyses community count tables in Julia. Samples are rows and features are columns. A Community also holds sample metadata and can include taxonomy, sequences, and a phylogenetic tree.

Create and analyse a community

Install with Julia's package manager (] add CommunityEcology) after registration. Until then, add the repository URL and the NonmetricMDS.jl dependency.

using CommunityEcology, DataFrames

counts = [8 1 0; 7 2 1; 0 1 9; 1 0 8]
meta = DataFrame(sample=["A1", "A2", "B1", "B2"], site=["A", "A", "B", "B"])
c = Community(counts; samples=meta.sample,
              features=["oak", "pine", "birch"], metadata=meta)

alpha_diversity(c)                 # one row per sample
d = beta_diversity(c, :braycurtis) # pairwise dissimilarities
ordinate(d, c, :pcoa)              # principal coordinates

For a multisite Jaccard decomposition, use beta_partition(c) or group by a metadata column:

beta_partition(c; family=:jaccard)
beta_partition(c, :site; family=:sorensen)

The decomposition returns total dissimilarity, turnover, and nestedness. The grouped result also reports within-group dispersion. Each group needs at least two samples.

Main workflows

  • alpha_diversity, rarefy, and specaccum describe within-sample diversity and accumulation.
  • beta_diversity, ordinate, and rda analyse differences among samples.
  • permanova, betadisper, mantel, and envfit test associations and group differences.
  • relative, hellinger, and presence_absence transform counts into new Community values.
  • write_community and read_community round-trip a community through files.

nmds and pcoa are provided by NonmetricMDS.jl; PERMANOVA and dispersion methods likewise use separate packages. Load a Makie backend to enable the optional plotting recipes. The README has a longer example and describes differences from R's vegan package.

CommunityEcology.Community — Type
Community

A community data set: a table of counts with one row per sample and one column per feature (ASV, OTU or taxon), with optional feature sequences, a taxonomy (one row per feature, one column per rank), sample metadata (one row per sample, first column sample) and a phylogenetic tree.

Construct one from a sequence table (DenoiseDNA's SequenceTable), from a count matrix, or read one saved with write_community:

c = Community(seqtab; taxonomy=taxa, metadata="samples.csv")
c = Community(counts; samples=names, features=ids)

Index it like a matrix, by position, Bool vector or name: c[1:5, :], c[:, ["ASV1", "ASV2"]], c[c.metadata.site .== "A", :].

CommunityEcology.Community — Method
Community(counts; samples, features, sequences=String[], taxonomy=nothing,
          metadata=nothing, tree=nothing, by=:sample)

counts is a samples × features matrix. A sequence table from DenoiseDNA (anything with samples, sequences and table fields) gives the counts, sample names and sequences; features are named ASV1, ASV2, … in table order.

  • taxonomy: any table with one row per feature (e.g. the TaxonomyTable from AssignTaxonomy). If it has a Sequence column, rows are matched to features by sequence; otherwise they must be in feature order.
  • metadata: a table or a CSV/TSV file with one row per sample, matched by the column by (default :sample). Samples without metadata get missing.
  • tree: a PhyloTree whose tips are the features.

CommunityEcology.beta_diversity — Function
beta_diversity(c, method=:braycurtis; pseudocount=0.5)

Dissimilarities between the samples of c:

  • :braycurtis: Bray-Curtis on counts, Σ|xᵢ - yᵢ| / Σ(xᵢ + yᵢ) (use relative(c) first to weight samples equally)
  • :jaccard, :sorensen: on presence/absence
  • :ruzicka: quantitative Jaccard (as vegan::vegdist(method="jaccard"))
  • :manhattan, :canberra (mean over non-double-zero features), :gower (feature-range-scaled mean absolute difference)
  • :euclidean, :chord, :hellinger (Euclidean on transformed data), :aitchison (Euclidean on the centred log-ratio, with pseudocount)
  • :unifrac, :wunifrac: unweighted and weighted (normalised) UniFrac (Lozupone & Knight 2005; Lozupone et al. 2007), which need a tree

Samples with no reads are rejected: drop them with prune.

CommunityEcology.beta_partition — Method
beta_partition(c, groups::Symbol...; family=:jaccard, dispersion=:braycurtis, digits=2)

The multi-site β-diversity partition (see beta_partition(c)) for each group of samples, the groups being the combinations of the metadata columns groups, in order of appearance. With dispersion set to a dissimilarity (see beta_diversity), each group's dispersion is added: the mean distance of its samples to the group centroid in principal coordinate space (betadisper with type=:centroid), computed on c as given; pass relative(c) for dispersion of proportions. dispersion=nothing leaves it out.

beta_partition(relative(c), :transfer, :carbon)   # one row per transfer × carbon source
source
CommunityEcology.beta_partition — Method
beta_partition(c; family=:jaccard)

Multi-site β-diversity of the samples of c, from presence/absence, and its partition into species turnover and nestedness (Baselga 2010, 2012; as betapart::beta.multi). With Sᵢ the richness of sample i, S_T the total richness, and bᵢⱼ the number of species in i but not j, summed over pairs of samples as min = Σ min(bᵢⱼ, bⱼᵢ) and max = Σ max(bᵢⱼ, bⱼᵢ), and a = Σ Sᵢ - S_T:

  • family=:jaccard: total βJAC = (min + max) / (a + min + max), turnover βJTU = 2min / (a + 2min), nestedness βJNE = βJAC - βJTU;
  • family=:sorensen: βSOR = (min + max) / (2a + min + max), βSIM = min / (a + min), βSNE = βSOR - βSIM.

Returns (total, turnover, nestedness, relative_turnover), the last being turnover / total. For one table per group of samples, see beta_partition(c, groups...).

beta_partition(dune())          # (total = 0.88…, turnover = 0.81…, nestedness = 0.07…, …)

CommunityEcology.build_tree — Method
build_tree(c::Community; band=32)
build_tree(seqs; labels, band=32)

A neighbour-joining tree (rooted at its midpoint) of the feature sequences of c, from Jukes-Cantor distances of pairwise alignments; returns a copy of c with the tree attached, ready for UniFrac and Faith's PD. Given sequences, returns the PhyloTree.

This is a quick distance tree, good enough for UniFrac and for a picture. For a phylogeny to interpret on its own, align with a multiple aligner and build a maximum-likelihood tree; read_newick reads the result.

CommunityEcology.chao1 — Method
chao1(x)

Bias-corrected Chao1 estimate of richness, S + F₁(F₁ - 1) / (2(F₂ + 1)), from integer counts (F₁ singletons, F₂ doubletons), as vegan::estimateR. Denoised ASV tables contain few singletons, which makes Chao1 close to the observed richness there.

CommunityEcology.mantel — Method
mantel(a, b; method=:pearson, alternative=:greater, permutations=999,
       rng=Random.default_rng())

Mantel test of association between two distance matrices with the same sample order. method=:spearman correlates average ranks (including ties). The permutation test relabels the rows and columns of b together. The p-value includes the observed arrangement, so its minimum is 1/(permutations+1). Use alternative=:less or :two_sided for other tails.

CommunityEcology.rda — Method
rda(c::Community, predictors; transform=:hellinger, k=2)

Redundancy analysis of a community table constrained by numeric or categorical sample metadata columns. The response is Hellinger transformed by default; :relative and :raw are also available. Numeric predictors are centred; categorical predictors use reference-level dummy coding. The result contains fitted sample coordinates (sites), feature loadings (feature_scores), constrained eigenvalues, and adjusted R². Permutation inference for a model can be performed separately with permanova.

This is a basic RDA with no conditioning terms, weights, or formula interface.

CommunityEcology.simper — Method
simper(c::Community, variable::Symbol; relative=false)

Break down mean between-group Bray–Curtis dissimilarity into contributions from individual features. Returns a DataFrame for every pair of levels in the metadata column variable, ordered by decreasing mean contribution. average is the mean contribution on the Bray–Curtis scale; fraction and cumulative divide by the total mean dissimilarity. mean_a and mean_b are group mean abundances. relative=true first converts each sample to relative abundance. Missing group labels are omitted.

SIMPER is descriptive: a high contribution can reflect abundant, variable features even without a consistent group difference. Use permanova for a group-level permutation test.

varespec()

Cover of 44 lichen, moss and vascular plant species in 24 lichen pastures under Scots pine in eastern Fennoscandia (Väre, Ohtonen & Oksanen 1995), with soil chemistry as metadata: N, P, K, Ca, Mg, S, Al, Fe, Mn, Zn, Mo (mg/kg), Baresoil (% cover), Humdepth (humus depth, cm) and pH.

The same data as varespec and varechem in R's vegan package.

CommunityEcology.wisconsin — Method
wisconsin(c)

Wisconsin double standardization: divide each feature by its maximum across samples, then divide each sample by its resulting total. All-zero features and samples remain zero.
